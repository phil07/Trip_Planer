# Installation: Skills und Plugins

Dieses Projekt nutzt die folgenden Skills und Plugins aus dem Anthropic Plugin Directory. Jeder KI-Assistent, der dieses Repo öffnet, soll sie installieren, bevor er mit der Arbeit beginnt, sofern sie nicht schon aktiv sind.

Keine Zugangsdaten nötig. Keine Anmeldung bei Drittdiensten nötig.

## Zu installieren

| Plugin | Marketplace | Zweck |
| --- | --- | --- |
| Superpowers (obra) | Anthropic Directory | Kern-Skills: TDD, Debugging, Pläne, Code-Review |
| caveman | Anthropic Directory | Kurze, knappe Antworten, spart Tokens |
| Humanizer (blader) | Anthropic Directory | Entfernt KI-typische Formulierungen aus Texten |
| audit-suite (enthält emil-design-engineering) | Anthropic Directory | Design- und UI-Details, Prüfung aus Sicht verschiedener Ingenieure |
| AI Skills (enthält find-skills) | Anthropic Directory | Findet passende Skills für eine Aufgabe |

## Nicht gefunden

## Vorgehen für den Assistenten

1. Prüfe, welche der Plugins aus der Tabelle bereits aktiv sind.
2. Installiere die fehlenden über den Plugin-Katalog (Suche per Stichwort, dann Installation).
3. Melde dem Nutzer, welche installiert wurden und welche nicht gefunden wurden.
4. Installiere keine Plugins, die Zugangsdaten verlangen. Frage den Nutzer vorher.
